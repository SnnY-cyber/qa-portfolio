# QA Engineer Portfolio

A responsive Turkish portfolio site for QA engineering, built as a static HTML page.

## Live site
GitHub Pages: `https://snny-cyber.github.io/qa-portfolio/` (enable Pages from Settings → Pages → Deploy from a branch → `main` / root).

## Projects
Automation samples live in [qa-automation-projects](https://github.com/SnnY-cyber/qa-automation-projects): Playwright UI/API/visual tests and an Appium mobile starter.

## Customize
Update the email and LinkedIn placeholders in `index.html` before sharing them. The GitHub profile and project links are already configured.
